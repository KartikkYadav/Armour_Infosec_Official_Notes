## Overview

Every repository follows the same idea: learn by doing. Notes explain the concept, labs let you reproduce it, and fixes show how to defend against it. Content spans web application security, Windows and Linux privilege escalation, file transfer techniques, wireless penetration testing, secure PHP and WordPress, Python for security work, and enterprise Windows and Linux hardening. Where applicable, material is mapped to recognised frameworks and certifications such as OWASP WSTG, the PortSwigger Top 10, RHCSA and LFCS.

## Repositories

### Tooling

**[surfacemap](https://github.com/armourinfosec/surfacemap)** — Python
Maps one authorized web origin's attack surface: hosts, technologies, routes, parameters, identities and trust boundaries, delivered as an evidenced, ranked handoff.

### Offensive Security

**[Offensive-Web-Application-Security](https://github.com/armourinfosec/Offensive-Web-Application-Security)**
A lab-driven course on breaking web applications and explaining how to fix them. 491 notes and 36 reproducible labs, mapped to OWASP WSTG and the PortSwigger Top 10.

**[Offensive-Windows-Privilege-Escalation](https://github.com/armourinfosec/Offensive-Windows-Privilege-Escalation)**
Hands-on study notes: enumeration and methodology, service and scheduled-task misconfigurations, UAC bypass, token-privilege abuse, and more.

**[Offensive-Linux-Privilege-Escalation](https://github.com/armourinfosec/Offensive-Linux-Privilege-Escalation)**
Hands-on study notes: enumeration, sudo/SUID/capabilities, cron and systemd timers, kernel LPEs (DirtyPipe, OverlayFS, PwnKit) and more.

**[Offensive-File-Transfer-Techniques](https://github.com/armourinfosec/Offensive-File-Transfer-Techniques)**
Hands-on notes on moving files to and from a target during an engagement across every channel: HTTP, SMB, FTP, TFTP, WebDAV and more.

**[Wireless-Security-and-WiFi-Penetration-Testing](https://github.com/armourinfosec/Wireless-Security-and-WiFi-Penetration-Testing)**
Open, hands-on notes on wireless security and Wi-Fi penetration testing: 802.11, WEP/WPA/WPA2/WPA3, aircrack-ng. CC BY 4.0.

### Secure Development

**[Python-for-Security-Professionals](https://github.com/armourinfosec/Python-for-Security-Professionals)**
Lab-driven notes: language fundamentals, the standard library, concurrency and packaging, then building port scanners and other security tools.

**[Secure-PHP-Development](https://github.com/armourinfosec/Secure-PHP-Development)**
Lab-driven notes: modern PHP 8.2/8.3 through a full OWASP-mapped catalogue of PHP vulnerabilities, with exploit-then-fix labs.

**[Secure-WordPress-Administration](https://github.com/armourinfosec/Secure-WordPress-Administration)**
Open-source, lab-driven notes for building, administering, hardening and operating WordPress at scale. 28 modules covering install, content, security, performance and more.

### Administration and Hardening

**[Linux-Administration-and-Server-Hardening](https://github.com/armourinfosec/Linux-Administration-and-Server-Hardening)**
Lab-driven, dual-distro (CentOS Stream 10 / Debian 12) course. 29 modules, 20 labs and 10 enterprise projects, aligned to RHCSA and LFCS.

**[Enterprise-Windows-Infrastructure-Security](https://github.com/armourinfosec/Enterprise-Windows-Infrastructure-Security)**
An Obsidian-based knowledge base for Windows Server administration and defensive hardening.
